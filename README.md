# AI Media Studio

A mobile-first AI creator workspace.

## Included
- Dashboard and creator workspace
- Image, video, frame and storyboard tool modes
- Prompt composer and demo generation history
- API health endpoint at /api/health
- No client-side API keys

## Run
npm install
npm run dev

## Next integrations
Connect an approved model provider through server-side environment variables. Add authentication, persistent generation history, usage enforcement, and real media generation without exposing secrets in the browser.
